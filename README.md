# My First Project

Welcome to Vee Atlas — a personal planning and goal-tracking workspace.

## Overview

This project is a collection of structured templates and frameworks to help
organize goals, priorities, and daily habits in one place.

## Structure

- **10-80-10** — Planning framework for breaking down big goals
- **Annual Goals** — Yearly objectives and milestones
- **Big 3** — Daily top three priorities

## Getting Started

Clone the repository and explore each folder to find the templates that
work best for your workflow.

```bash
git clone https://github.com/vernalynnciriacoofficial-prog/Vee-Atlas.git
```
