Animation Principles
🎯
Purpose over flair
Every animation should communicate something: state change, direction, hierarchy. If you can't explain why it moves, remove it.
⚡
Fast enough to feel instant
UI transitions should never feel slow. Default to 200ms. Only go slower for content reveals or complex orchestration.
♿
Respect prefers-reduced-motion
Always wrap animations with a @media (prefers-reduced-motion: reduce) override that removes transitions.
06 — Resources

How to Use This System

Three files. Drop them into any Atlas project and you're on-brand immediately.

FILE 1
tokens.css
All CSS custom properties (--atlas-*). Import once at the root of any project. Works in vanilla HTML, React, Vue — anything.
@import './design-system/tokens.css';
FILE 2
tailwind.preset.js
Drop into any Tailwind project. Adds all atlas.* color classes, font families, animations, and custom utilities.
presets: [require('./design-system/tailwind.preset')]
FILE 3
index.html
This page. Open it in any browser for the full visual reference. Share the link with teammates, include in project READMEs.
open design-system/index.html
💡
Google Fonts required
Include this in the <head> of every project: https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,300..900;1,9..144,300..900&family=Plus+Jakarta+Sans:wght@300;400;500;600;700;800&family=JetBrains+Mono:wght@400;500&display=swap
